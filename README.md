# Screen Time, Sleep & Academic Performance Analysis – Data Cleaning

## 1. Project Overview

This project involves exploring and preparing a student dataset containing information about sleep patterns, screen time, lifestyle habits, and academic performance.

The dataset was sourced from Kaggle and consists of 500 records and 25 columns. The current work focuses on inspecting, cleaning, and transforming the raw data using Microsoft Excel and Power Query to improve data quality, consistency, and accuracy before further analysis.

## 2. Dataset Information

- **Source:** Kaggle
- **Number of Rows:** 500
- **Number of Columns:** 25
- **Domain:** Student Sleep, Screen Time and Academic Performance

## 3. Tools Used

- Microsoft Excel
- Power Query

## 4. Data Cleaning and Transformation

The following data-cleaning activities were performed:

- Checked column names and data consistency.
- Identified missing and null values.
- Checked for duplicate records.
- Standardised gender categories.
- Handled missing values based on column data types.
- Checked numerical columns for invalid values.
- Rounded decimal values where required.
- Corrected column data types.
- Checked negative values and retained valid numerical differences.

## 5. Objective

The objective of this stage is to improve data quality, maintain consistency, and prepare the dataset for further analysis.

## 6. Current Project Status

**Completed:**

- Initial data inspection.
- Data cleaning using Excel.
- Data transformation using Power Query.
- Handling missing and inconsistent values.

**Future Work:**

- Data analysis.
- Data modelling.
- DAX calculations.
- Dashboard creation using Power BI.

## 7. Conclusion

Data cleaning is an essential step in the data analytics process. This project currently focuses on cleaning and preparing the dataset using Excel and Power Query to ensure that it is ready for further analysis.
